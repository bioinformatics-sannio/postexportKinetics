## 4. Exact and tolerance comparisons

### 4.1 Tolerances used in the tests

Comparisons are elementwise: `|a − e| ≤ abs + rel·|e|`. Structure is
compared exactly: type, class, names, dims, dimnames, NA/NaN/Inf pattern and
other attributes. Error cases require an identical error message.

| Tier | Tolerance | Applied to | Justification |
|---|---|---|---|
| T0 | exact | constants, `build_sigma_means`, `build_difference_matrix`, p-values, `atom.zero`, failure rates, prefix property, error messages | discrete quantities or pure copying |
| T1 | rel 1e-12, abs 1e-14 | Crank–Nicolson (4×4 `solve`) | pure arithmetic with LU solves; no eigendecomposition |
| T2 | rel 1e-10, abs 1e-14 | `make_spd`, whitening, covariance, interval balance, NNLS fits, bootstrap draws and T\* | eigen/SVD/NNLS paths. Error scales as κ·ε, where κ is the condition number and ε machine precision; margin is left for BLAS differences. An NNLS active-set change is a discontinuity and would still fail. |
| — | rel 1e-8 | package vs deposited TSV | the TSV was written with 15 significant digits (`fwrite`) |

Bootstrap-draw comparisons are guarded. They run only when LAPACK, BLAS, OS,
architecture, `MASS`, `nnls` and `RNGkind()` all match the fixture
provenance; otherwise they are skipped with a reason. They ran here, because
this is the fixture platform.

## 7. Unresolved issues and decisions for review

1. **Version number.** The development version is `0.0.0.9000`. Bioconductor
   requires `0.99.z` for new submissions, while the review refers to
   "v0.1.0". Please decide when to move to `0.99.0`.
2. **Indentation of ported code.** Should the verbatim ports be reformatted to
   4-space indentation (for BiocCheck)? It is a purely mechanical change;
   `test-verbatim-port.R` compares deparsed expressions, so equivalence stays
   enforced. Until approved, the frozen formatting is kept, which makes
   line-by-line diffs against the tag trivial.
3. **`paste()` in `stop()` and function length** (BiocCheck NOTEs) come from
   verbatim frozen code. I propose leaving them unchanged in the internal
   ports. Public wrappers in later phases will follow Bioconductor style.
4. **Authors@R.** Co-author given names are recorded as initials ("L.",
   "F.", "M."), as in the frozen `CITATION.cff`. The maintainer is Luigi
   Cerulo, `luigi.cerulo@gmail.com`. No ORCID, `URL` or `BugReports` was
   invented. Please supply these, and confirm the copyright holder text
   ("postexportKinetics authors") in `LICENSE`.
5. **Orchestration not ported yet.** `test_sigma_nested`'s orchestration
   (status codes, failure-rate rule, diagnostics assembly) is exercised
   through the composition test in `tests/`. The package port and the
   wrapper `test_postexport_conversion()` are Phase 2. The fixture
   `fx_test_sigma_nested` already contains the full frozen return lists,
   including the `observed_system_failed` path, for that port.
6. **Failure-path fixtures** for `observed_fit_failed`,
   `null_trajectory_failed` and `bootstrap_unstable` are not yet present:
   these states are hard to trigger with realistic data. I propose
   constructing them in Phase 2 by calling the frozen orchestrator with
   `max_failure_rate = 0` on a design with rare bootstrap failures, or with
   stubbed inputs.
7. **Cross-platform behaviour.** Bootstrap-draw fixtures are platform
   specific (the frozen benchmark ran on OpenBLAS 0.3.3 / LAPACK 3.8.0 /
   Linux; the fixtures were made on macOS with reference BLAS). On other
   platforms those tests skip. The deterministic tests are expected to pass
   at the T1/T2 tolerances, but this has only been verified on this machine.
   A Linux CI run is recommended before Phase 2 is merged.
8. **Tooling not available here.** `pandoc` and LaTeX (for the PDF manual)
   are not installed, so `R CMD check` ran with `--no-manual`.
9. **License file replaced.** The GPL-3 `LICENSE` from the repository's
   initial commit has been overwritten with MIT files, per decision SF-14.
