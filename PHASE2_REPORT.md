## 4. Validation rules (`validate_postexport_data()`, used by `postexport_data()`)

**Errors (block construction):**

- missing identifier columns (`event`, `time`, `replicate`);
- missing state columns (all four of `N`, `N_s`, `C`, `C_s` required);
- `columns` mapping invalid;
- missing identifier values;
- non-numeric or non-finite `time`;
- non-numeric state columns;
- missing (`NA`) or non-finite state values (**no zero-filling, no
  imputation**);
- duplicated `event`/`time`/`replicate`;
- long format: missing columns, invalid compartment/state labels, duplicated
  observations (**never aggregated**), samples lacking one or more states;
- an event with fewer than 2 distinct time points (frozen requirement);
- an event without a time point with ≥ 2 replicates (frozen requirement);
- invalid `t_star`.

**Warning:** negative abundances. The wording is as approved: states are
non-negative biologically, negative values can arise after normalization or
noise processing, and they are accepted by the frozen core. Values are not
truncated, imputed or replaced (tested).

**Diagnostic information** (no thresholds):

- unsorted times;
- unequal replication;
- time points with a single replicate (the pooled covariance is used there);
- exactly two time points;
- `t_star` at or before the first sample (R column identically zero, R not
  estimable, condition number infinite by construction);
- `t_star` at or after the last sample.

`time_unit` is required by `postexport_data()`.

**Long format mapping (fixed, documented):**

| compartment | state | kinetic state |
|---|---|---|
| nuclear | unprocessed | `N` |
| nuclear | processed | `N_s` |
| cytoplasmic | unprocessed | `C` |
| cytoplasmic | processed | `C_s` |

No other labels are accepted, and nothing is inferred from column names.
Other column names can be declared only through `columns`.

## 5. S3 object structure

`postexport_fit` (single event):

```
event, status, error_message       frozen status codes
estimates  $sigma_c                effect-size estimate (phenomenological rate)
           $coef_full, $coef_null  named (R, tau, tau_s, sigma_c, sigma_n, alpha, alpha_s)
fit        $RSS_null, $RSS_full, $T_obs, $delta_RSS, $IR
boundary   $tolerance (1e-10*max(1,|RSS0|,|RSS1|)), $at_boundary, $sigma_c_zero
diagnostics $condition_number, $min_singular_value, $rank_full, $rank_null,
            $pooled_covariance, $structurally_zero_columns,
            $condition_number_nonzero_columns (diagnostic only)
design     $t_star, $time_unit, $intervention, $times, $n_replicates_by_time
system     interval-balance system (A, b, Sigma_b, Sigma_m, D, col_norms, summary)
control, provenance (package version, frozen tag/commit)
```

`postexport_test` = `c("postexport_test", "postexport_fit")`. The fit
fields are taken from the frozen result, plus:

```
inference  $p_value (bootstrap, one-sided), $B, $n_bootstrap_valid,
           $bootstrap_failure_rate, $atom_zero, $T_boot,
           $statistic, $alternative, $method (text)
bootstrap_diagnostics  $condition_median/q95/max, $rank_deficient_fraction
null_means             CN null trajectory used by the bootstrap
rng        $seed, $kind (RNGkind()), $random_seed_before (seed = NULL), $note
raw        complete frozen test_sigma_nested() list
```

Several events give `postexport_fit_set` / `postexport_test_set`, each a list
with:

- `summary`: a data frame with one row per event: event, status, sigma_c, IR,
  T_obs, RSS, boundary, condition number, rank and, for tests, p_value, B,
  valid, failure rate, atom_zero;
- `results`: a named list of per-event objects;
- `t_star`, `time_unit`, `control`, `provenance`.

Separation of quantities:

- the inferential p-value is only in `inference$p_value` / `summary$p_value`;
- the effect-size estimate is `estimates$sigma_c`;
- there is no ranking score and no q-value.

`print()` labels them "Inference", "Effect size" and "Fit", and prints the
interpretation note. The wording is tested: output never contains
"splicing", "detected" or "q-value", and it contains "post-export conversion
component" and "not a likelihood-ratio test".

**Seeds:**

- single event: `seed` as in the frozen code (`set.seed()` before the
  observed fit);
- several events: a named per-event seed vector, or `seed = NULL` (sequential
  stream; the state before each event is recorded);
- a scalar seed with several events is an error, because it would give every
  event the same bootstrap stream.

## 10. Unresolved decisions

1. **`t_star` placement.** It is an explicit required argument of
   `fit_postexport_model()` and `test_postexport_conversion()`, with
   `NULL` meaning continuous transcription, not a `postexport_control()`
   setting. Rationale: it is a property of the experimental design, and the
   approved plan requires that intervention semantics are never hidden behind
   a default. Please confirm, or ask for it to move into the control object.
2. **`seed` and the global random-number state.** Frozen behaviour is kept:
   `set.seed(seed)` changes the caller's global RNG state, which is also the
   origin of the BiocCheck `set.seed` WARNING. Restoring the caller's RNG
   state afterwards would not change any number (open plan item 16.B-3).
   A Bioconductor-motivated change inside the frozen port needs approval.
3. **Default per-event seed scheme for batches.** Phase 2 requires explicit
   named per-event seeds, or `seed = NULL`; a single scalar seed for several
   events is refused. A derived scheme (e.g. hashing seed and event as in
   the benchmark scripts) is left for the batch phase.
4. **Diagnostic information vs warnings.** Single-replicate time points,
   exactly two time points and `t_star` outside the sampled window are
   reported as *information*, not warnings. The plan draft had listed some of
   them as warnings; Phase 2 limits warnings to negative abundances as
   instructed. Please confirm.
5. **Long-format vocabulary.** Only `nuclear`/`cytoplasmic` and
   `unprocessed`/`processed` are accepted; there are no aliases such as
   `nuc`/`cyt` or `inclusion`/`skipping`. Aliases could be added as an
   explicitly documented list if wanted.
6. **Exposed advanced options.** `scaling_A` and
   `truncate_nonnegative_boot` are exposed with their frozen defaults and
   documented effects. Please confirm they should be public.
7. **Validation stricter than the frozen core.** `B` must be a whole number;
   `rel_floor > 0`; `max_failure_rate` in `[0, 1]`. The frozen code accepted
   these values silently (e.g. negative `max_failure_rate`). No accepted
   input changes behaviour.
8. **Unreachable frozen statuses.** `observed_fit_failed` and
   `null_trajectory_failed` have no realistic constructed fixture. They are
   covered by the verbatim-port check of the orchestrator and are handled by
   the result constructor.
9. **Function length.** New validation, result and print functions exceed
   50 lines (BiocCheck NOTE). They could be split in a later clean-up
   without behavioural change.
10. **Merge.** `phase2-api` is not merged to `main`, pending review.
